Chess Opening Memorizer: 
A Java console-based game designed to help users memorize common chess openings.


About: 
I created this project to combine my interest in chess and computer science. The program randomly selects one of 20 chess openings, displays its starting move sequence, and asks the user to identify the opening. The program continues presenting openings until the user chooses to quit.

Example:
Chess Line: e4 e5 Nf3 Nc6 Bb5
(Enter 'End' to quit) Chess Opening Name: Ruy Lopez


Technologies: 
Java


Concepts Used:
- Object-oriented programming
- Classes and objects
- Constructors
- Encapsulation
- ArrayLists
- Loops and conditional statements
- User input with Scanner
- Random number generation
- String comparison


Project Structure:   
Main.java — Runs the memorization game and manages the list of chess openings. Defines the chessOpening class and stores each opening's name and move sequence.
